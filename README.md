## ✨ Features

- 🌊 **Responsive Design** — Optimized for mobile, tablet & desktop
- 📸 **Photo Gallery** — Showcasing surf sessions and school activities
- 📅 **Course Booking** — Browse available surf lessons and packages
- 📍 **Location & Contact** — Integrated map and contact form
- ⚡ **Fast & Lightweight** — Pure HTML/CSS/JS, no framework overhead

## 🚀 Quick Start

```bash
# Clone the repo
git clone https://github.com/salahABOU03/Surf_School_Essaouira.git

# Open in browser
open index.html
```
